1. Build the project
I want to build a website called BalanceVault where people can manage their bank accounts and money in one place. Please make it simple to use and give it a clean, modern look. I want users to be able to check their balances, see money coming in and going out, view accounts, and make transfers.
2. Make the dashboard
Can you make a home page for BalanceVault? I want a menu on the left with Overview, Accounts, Statements, Account Request, and Money Transfer.
On the main page, show the user's total balance, money available to spend, money coming in, money going out, and active accounts. Keep everything neat and easy to understand.
3. Add bank accounts
I want users to see their bank accounts in one place. Please add an Accounts page where they can select an account and view its details. Also add an option to open a new account.
4. Add account requests
Can you add an Account Request page? Users should be able to fill in a form and send a request for a new account. After they submit it, show them a message so they know what happened.
5. Add statements
Please add a Statements page where users can find and view their account statements. Keep the page simple, and show the account and statement date clearly. If downloading statements is supported, add a download option too.
6. Add transactions
I want users to be able to add their transactions. Please add an Add Transaction option where they can enter the amount, date, type, and a short description. Let them choose whether money came in or went out.
7. Add Send Money
Can you add a Send Money option? Users should be able to enter the receiver's details and the amount they want to send. Before the money is sent, show the details and ask them to confirm.
8. Add Money Transfer
Please make the Money Transfer section easy to use. Let users enter the details needed for a transfer, check the amount, and see the transfer status afterwards. Don't show a transfer as successful unless the app confirms it.
9. Add routing details
I want users to find their routing and account details easily. Please connect the View Routing & Details option on the dashboard to a page that shows the details available for their account.
10. Add the vault card
Can you make the Primary Vault Card section look like a real bank card? Show the card type and status, but hide most of the card number for safety.
11. Add Hide Numbers
Please add a Hide Numbers option. When users click it, hide their account and card numbers. When they want to see them again, let them show the numbers safely.
12. Show verification status
I want users to see their account verification level on the dashboard. Please show a clear label, such as Tier 2 Verified, when that is the actual status of their account.
13. Connect the dashboard figures
Please make sure the numbers on the dashboard come from the actual account and transaction data. When a user adds a transaction or makes a confirmed change, update the related figures. Don't show made-up balances or transactions.
14. Make the website look better
Can you go through the BalanceVault pages and make the design look consistent? Use the same colours, fonts, buttons, and card styles. Please make sure it also looks good on a mobile phone.
15. Make the website easier to use
Please check the buttons and forms on every page. If someone misses a required detail or something goes wrong, show a friendly message that explains what they should do next.
16. Keep account details safe
Can you check that users only see the account information they're allowed to see? Keep sensitive numbers hidden when possible, and ask users to confirm before important money actions. Never show passwords, PINs, or one-time codes.
17. Fix any problems
Please go through the whole BalanceVault website and check if all the pages and buttons are working. Fix any problems you find, but don't remove features that are already working.
18. Check the money features
Can you test adding a transaction, sending money, and making a transfer? Make sure the app checks the details before submitting and shows the correct result afterwards. Don't say a payment worked unless the app confirms it.
19. Check the account features
Please test opening an account, sending an account request, viewing account details, and checking statements. Make sure each option takes the user to the right place and shows a clear message.
20. Give me a final project review
Can you review BalanceVault from a user's point of view? Tell me what is working, what needs fixing, and which features still need backend support. Please explain any problems in simple words.
